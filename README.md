# FinSentinel

FinSentinel is an explainable financial signal analysis app.

It combines FinBERT-based financial news sentiment, stock price data, technical indicators, risk filters, and Buy/Hold/Sell signal generation through a Gradio interface.

## Project Structure

FinSentinel/
- app.py
- requirements.txt
- README.md
- .gitignore
- src/
- data/
- models/
- outputs/
- notebooks/
- tests/

## Run Locally

Activate the virtual environment:

venv\Scripts\activate

Run the app:

python app.py
